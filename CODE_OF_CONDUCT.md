# Code of Conduct

## Our standard

This project welcomes focused, respectful collaboration. Discuss behavior and
evidence rather than a person's background or ability. Assume good intent,
accept correction, and keep reports safe for a public repository.

Harassment, threats, discriminatory language, deliberate disclosure of private
information, and repeated disruption are not acceptable.

## Project-specific safety

Do not post credentials, unreviewed Harness homes, private source code, or raw
session exports. Redact local paths and identifying data before sharing a field
report. Use GitHub's private vulnerability reporting channel for a security or
privacy issue.

## Enforcement

The maintainer may edit or remove contributions that violate these standards,
close disruptive interactions, or restrict participation when necessary. For a
non-security conduct concern that cannot be raised safely in public, use a
minimal GitHub issue asking for a private follow-up without including the
sensitive details.

This policy applies in the repository and in project-related public community
spaces.
